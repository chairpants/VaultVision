## Source notes

Found via the AutoArchive library database (`library-db/`, export of
2026-11-12). Episode numbering and titles were checked against TVmaze's
episode list (https://www.tvmaze.com/shows/1109).

Files are named by code only (`Judging Amy   S01E01 Remasterd 4K UHD …`, which
are 720p upscales). Per-season counts (23/22/24/24/23/22) match the broadcast
record exactly, so per `ADDING_A_SHOW.md` §1c the numbering is trusted and
titles come from the episode list by position. That is an educated guess, not
a frame-by-frame check: if a file sits somewhere other than its code claims,
its title here will be wrong.
