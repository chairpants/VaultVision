## Source notes

Found via the AutoArchive library database (`library-db/`, export of
2026-11-12). Episode numbering and titles were checked against TVmaze's
episode list (https://www.tvmaze.com/shows/815) and, where the two
disagreed, Wikipedia.

Season 1 files carry titles and agree with the broadcast record. Season 2
files are named by code only (`Reaper_S02E01.mp4` …); their count (13)
matches the record, so per `ADDING_A_SHOW.md` §1c the numbering is trusted
and titles come from the episode list by position. That is an educated
guess, not a frame-by-frame check: if a season 2 file sits somewhere other
than its code claims, its title here will be wrong.

Original `.mp4` uploads, h.264/AAC, 638×360, ~40 min episodes.
