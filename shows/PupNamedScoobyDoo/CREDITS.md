## Source notes

Found via the AutoArchive library database (`library-db/`, export of
2026-11-12). Episode numbering and titles were checked against TVmaze's
episode list (https://www.tvmaze.com/shows/4796).

Files are named by code only. The item numbers season 3 as six episodes;
Wikipedia lists seasons 3 and 4 as three each (13/8/3/3 = 27), so the item's
S03E04–06 are season 4 here, and titles come from Wikipedia's list by
position. TVmaze counts some segments separately (30), so Wikipedia is the
source for this show. Labelled by position: an educated guess, not a
frame-by-frame check.
