## Source notes

Found via the AutoArchive library database (`library-db/`, export of
2026-11-12). Episode numbering and titles were checked against TVmaze's
episode list (https://www.tvmaze.com/shows/17992).

Files are coded `SxxEyy` (some by code only, some with titles) across three
items; per-season counts match the broadcast record except season 5, where
the item holds a tenth episode, "It's Red! It's Green! / Joseph Had a Little
Overcoat", that TVmaze doesn't list. It's kept, titled from its filename.
