## Source notes

Found via the AutoArchive library database (`library-db/`, export of
2026-11-12). Episode numbering and titles were checked against TVmaze's
episode list (https://www.tvmaze.com/shows/3956).

Files are named by code only (`Wildboyz.S01E01.DVDRip.XviD`). Per-season
counts (8/8/8/8) match the broadcast record, so titles come from the episode
list by position. Rows point at the archive's h.264 derivatives, not the
XviD uploads.
