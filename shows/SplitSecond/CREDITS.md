## Source notes

Single-file upload, uploader-labelled "Full Movie". Runtime (~90 min) matches
the film's known length, so nothing looks truncated. The file is an uploaded
`original` `MPEG4`/AAC with no Archive derivative, which is normal for
`.mp4` uploads — confirmed streamable directly (`ffprobe`: h264 video, AAC
audio).
