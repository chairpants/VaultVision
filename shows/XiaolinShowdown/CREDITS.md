## Source notes

Found via the AutoArchive library database (`library-db/`, export of
2026-11-12). Episode numbering and titles were checked against TVmaze's
episode list (https://www.tvmaze.com/shows/5949).

Season 1 files are named by code only (`XS 1x01`) and labelled by position;
seasons 2–3 carry titles, and every file was pinned by title. That swapped
two: season 2's "Screams of the Siren" and "The Emperor Scorpion Strikes
Back" were filed as E14/E16 and aired as E16/E14.
